# Task Management Tool (TMT) API

A REST API for managing tasks and projects.

## Project Structure

```
TMT/
├── api/
│   ├── __init__.py
│   ├── main.py
│   ├── models.py
│   └── utils.py
├── tests/
│   └── test_utils.py
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Running the API

```bash
python -m api.main
```
